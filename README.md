## Topics Explored
- Computer basics: IPOS, hardware, software and everyday computer systems
- Terminal: navigating folders, managing files, flags and pipes, and Homebrew
- Operating system: processes, storage, paths, permissions and OS responsibilities
- How programs run: compiler vs interpreter, and a Python program
- Number systems: binary, decimal, hexadecimal and text encoding
- Git and GitHub: commits, branches and Pull Requests
- Networking: LAN, MAN, WAN, DNS, routers, protocols and how a website opens

## How to run the number converter

1. Open a terminal in the project folder.
2. Run:

```
python3 mission-05-numbers-data/number_converter.py
```

3. Type a decimal number when it asks. The program prints the binary and hexadecimal form of that number.

## My Learning

1. I learned that staging selects the changes and committing saves them.
2. I learned how to use Terminal commands like `ls` to see files and `cd` to move between folders.
3. I learned how to understand file permissions (`rwx`) and convert numbers between binary and hexadecimal.
