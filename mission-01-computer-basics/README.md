# Mission 1: Know Your Computer

## 1. Task / objective

To understand the basic parts of a computer, the difference between hardware and software, and how computers work in everyday life.

## 2. Work completed

I identified computer components, studied the IPOS cycle, classified hardware and software, and explored everyday computer systems.

### Task 1.1: IPOS for taking and sharing a photo

| IPOS stage | What happens | Hardware / component |
|---|---|---|
| Input | The camera captures the photo and sends image data to the computer. | Camera |
| Processing | The computer processes the image and improves its quality. | CPU |
| Output | The photo is displayed on the screen. | Screen |
| Storage | The photo is saved so I can view it later. | SSD |
| Sharing | The photo is sent to a friend through the internet. | Wi-Fi card |

The camera captures the photo, and the computer processes and displays it. The photo is saved in storage and can be shared with others through the internet.
